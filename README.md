# Insight Global Job Matcher (MVP)
Synthetic resume + 5 synthetic jobs -> explainable skill-match scores -> CSV.
Python 3.11 stdlib only, no network.

Run: `python3 run_demo.py` -> `out/jobs.v1.json`, `out/matching_jobs.csv`.

Modules (`discover`, `report`, `apply`) share only the JSON contract. `apply` is an inactive placeholder.
